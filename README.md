# Vivaio Siracusa — catalogo statico

Sito mobile-first per presentare 29 varietà di agrumi, mostrare i formati e i prezzi al dettaglio e raccogliere richieste tramite WhatsApp.

## Anteprima locale
Aprire `index.html` in un browser. Non richiede installazioni né un server.

## Pubblicazione gratuita con GitHub Pages
1. Accedi a GitHub e crea un repository pubblico, ad esempio `vivaio-siracusa`.
2. Carica i file `index.html`, `styles.css`, `script.js` e la cartella `assets` (può restare vuota).
3. Nel repository vai su **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, branch `main`, cartella `/(root)`, poi **Save**.
5. Dopo la pubblicazione, GitHub mostrerà l'indirizzo del sito nella sezione Pages.
